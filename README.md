# ESP-BMP280

BMP280 pressure sensor driver for ESP-IDF (I2C).

## Installation

To install this component in your project, run the following command:

```sh
idf.py add-dependency pkwasniok/bmp280
```

## Usage

See usage examples in the `examples/` directory.
